# UV Commands Cheatlist

`uv python find`
- Finds the path to the Python interpreter used by UV.

`uv add <package_name>`
- Installs a Python package into the UV environment.

`uv run python -c "import sys; print(sys.prefix)"`
- View the path to the Python environment used by UV.

`uv tree`
- Displays the directory tree of the UV environment.

`uv pip list`
- View a Flat List of All Installed Packages
